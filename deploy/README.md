# Legacy DigitalOcean deployment (retired)

The scripts in this folder bootstrapped the old DigitalOcean droplet
(Caddy + Docker Compose). That droplet is no longer used or paid for.

Production now runs self-hosted under WSL behind a Cloudflare Tunnel.
See [`infra/self-hosted/README.md`](../infra/self-hosted/README.md).

These scripts are kept for reference only; do not run them for production.
